# Mathematical Notes

Public reader editions and reproducible Jupyter notebooks covering probability,
stochastic processes, stochastic calculus, and mathematical finance.

Website: <https://jiahaoli-creator.github.io/stochastic-calculus-notes/>

This is a living collection. Future updates will add more application-focused
material on stochastic volatility modelling, dynamic hedging, and exotic
option pricing.

## Contents

- Seven core reader chapters, from conditional expectation to Black–Scholes.
- Nine extended visual notebooks on projection, stopping times, maximal
  inequalities, quadratic variation, stochastic integration, Girsanov's
  theorem, and generators.
- A black-and-white quick-start page with a recommended reading sequence.
- Reader HTML hides Python input while retaining mathematical exposition,
  figures, simulations, and interpretation.
- The corresponding `.ipynb` source is available for reproducibility.
