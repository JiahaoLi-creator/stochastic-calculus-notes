1) Filtration & stopping times: “information” as a mathematical object¶

A filtration $(\mathcal F_t)$ is a formal model for “what is known by time $t$”.

A random time $\tau$ is a stopping time if, for every $t$, the event $\{\tau \le t\}$ is in $\mathcal F_t$.

Translation: by time $t$, you can decide whether you have already stopped.

This small measurability condition is exactly what allows “stopping” to interact nicely with conditional expectation.

What do we know at a random time?¶

For a stopping time $\tau$, the sigma-field at $\tau$ is

$$\mathcal F_\tau := \{A\in\mathcal F:\; A\cap\{\tau\le t\}\in\mathcal F_t,\;\forall t\}.$$

This encodes “all events whose truth can be determined once you stop”.

(If $\tau$ were not a stopping time, $\mathcal F_\tau$ would be a mess: you’d be smuggling future information.)

2) Optional sampling vs optional stopping¶

Optional sampling (safe form). If $(M_n)$ is a martingale and $\tau$ is a stopping time, then the stopped process

$$M_{n\wedge \tau}$$

is again a martingale. This is usually the first theorem you use (and it is extremely robust).

Optional stopping (dangerous form). To conclude something like

$$\mathbb E[M_\tau] = \mathbb E[M_0],$$

you need extra conditions (examples: bounded $\tau$, or UI of the stopped martingale, or integrability conditions that justify exchanging limits).

A useful mental model:

  • “Stopping the process” ($M_{n\wedge\tau}$) is a local operation → often OK.
  • “Taking expectations at the stopping time” ($\mathbb E[M_\tau]$) is a global operation → needs control of tails.

We’ll watch both succeed and fail, on purpose.

3) Visual intuition: sample paths + the stopping time $\tau$¶

We define the absorption time

$$\tau := \inf\{n\ge 0:\; S_n = A \text{ or } S_n=-B\}.$$

Then $S_{\tau}$ is either $A$ or $-B$.

The textbook move is:

  1. show $\tau$ is a stopping time;
  2. use optional sampling to get that $S_{n\wedge\tau}$ is a martingale;
  3. (with boundedness/UI) take $n\to\infty$ and get identities for $S_\tau$ and $\tau$.

4) Gambler’s ruin (unbiased): hitting probability¶

For the unbiased walk ($p=\frac{1}{2}$), the classic result is

$$\mathbb P(S_\tau = A) = \frac{B}{A+B}.$$

You can view this as an “affine harmonic function” principle: the function $h(x)=x$ is harmonic for the symmetric walk, and $h(S_{n\wedge\tau})$ is a martingale.

Let’s verify this numerically.

Theory B/(A+B)       = 0.58333

5) Gambler’s ruin (unbiased): expected time¶

A second martingale trick uses

$$M_n := S_n^2 - n,$$

which is a martingale for the symmetric walk.

Under conditions that justify optional stopping for $M_{n\wedge\tau}$, you get

$$\mathbb E[\tau] = AB.$$

We’ll estimate $\mathbb E[\tau]$ in simulation for a few $(A,B)$ pairs.

(A,B)=(6,6):   est E[tau]=36.42   theory=36
(A,B)=(8,12):   est E[tau]=96.73   theory=96
(A,B)=(10,14):   est E[tau]=140.55   theory=140
(A,B)=(12,10):   est E[tau]=121.49   theory=120
(A,B)=(15,15):   est E[tau]=222.24   theory=225

6) Biased walk: exponential martingale trick (the “tilt”)¶

When $p\neq \tfrac12$, $S_n$ is no longer a martingale.

But there is a standard fix: build an exponential martingale.

Let $\xi_i\in\{+1,-1\}$ with $\mathbb P(\xi_i=+1)=p$ and $q=1-p$.

Define the walk $S_n=\sum_{i=1}^n \xi_i$ (start at $0$ for simplicity). Then

$$M_n := \left(\frac{q}{p}\right)^{S_n}$$

is a (nonnegative) martingale.

Stopping at $\tau$ (hit $+A$ or $-B$) and applying optional stopping in the UI‑safe setting (bounded $M_{n\wedge\tau}$), you get a closed‑form hitting probability:

$$\mathbb P(S_\tau = A) = \frac{1 - (q/p)^B}{1 - (q/p)^{(A+B)}}, \qquad (p\neq\tfrac12).$$

Let’s test this numerically.

p=0.55, A=12, B=10
Estimated P(hit +A first) = 0.87640 (95% CI ~ [0.87317, 0.87963])
Theory                  = 0.87617

7) When optional stopping “fails”: first passage to +1¶

Here is the classic trap.

Let $(S_n)$ be a symmetric random walk starting at $0$, and define

$$\tau := \inf\{n\ge 0: S_n = 1\}.$$

Then $S_\tau \equiv 1$ almost surely, so $\mathbb E[S_\tau]=1$.

But $S_n$ is a martingale with $\mathbb E[S_n]=0$ for all $n$, so a naive “optional stopping” claim

$$\mathbb E[S_\tau] = \mathbb E[S_0]=0$$

is false.

What is true (and always safe) is: for each fixed $N$,

$$\mathbb E[S_{\tau\wedge N}] = 0$$

because $S_{\tau\wedge N}$ is a stopped martingale and bounded by a function of $N$.

The failure is the failure of exchanging limits:

$$\lim_{N\to\infty} \mathbb E[S_{\tau\wedge N}] \neq \mathbb E[\lim_{N\to\infty} S_{\tau\wedge N}].$$

Let’s see this.

8) Doob maximal inequality: turning “max over time” into a controlled quantity¶

A recurring pattern in martingale theory:

Maxima are scary, but we can often control them by expectations.

A useful version is the tail bound

$$\mathbb P\Big(\sup_{m\le t\le n}|M_t-M_m|>\alpha\Big) \le \frac{1}{\alpha}\mathbb E|M_n-M_m| \le \frac{1}{\alpha}\sqrt{\mathbb E|M_n-M_m|^2}.$$

Let’s numerically check the shape of the inequality on $M_t=S_t$ (symmetric walk), with $m=0$.

alpha | P(sup|S_t|>alpha) | E|S_n|/alpha | sqrt(E[S_n^2])/alpha
   10 |            0.97942 |      1.58943 |            1.98918
   15 |            0.81907 |      1.05962 |            1.32612
   20 |            0.58590 |      0.79472 |            0.99459
   25 |            0.38882 |      0.63577 |            0.79567

9) Bonus: Brownian exit from an interval (continuous-time echo)¶

The Brownian analogue is beautifully parallel:

Let $(B_t)$ be Brownian motion and

$$\tau := \inf\{t\ge 0:\; B_t = A \text{ or } B_t=-B\}.$$

Then (same formulas!)

$$\mathbb P(B_\tau=A) = \frac{B}{A+B}, \qquad \mathbb E[\tau]=AB.$$

Why? Because $B_t$ and $B_t^2-t$ are martingales, and optional stopping works here (with the right integrability/approximation arguments).

We’ll just simulate to see the pattern.

Estimated P(B_tau hits +A first) ~ 0.4000
Theory B/(A+B)                 = 0.4000
Estimated E[tau] (truncated if no exit by T): 0.9857
Theory E[tau]=AB                                  : 0.9600

10) Local martingales: when you can only prove things “up to a stopping time”¶

Later (especially in stochastic calculus), you meet processes that are local martingales: they behave like martingales after you stop them early enough, but may fail to be true martingales globally.

Two practical takeaways:

  1. Localization: prove a statement for $M^{T_n}$ where $T_n\uparrow\infty$ and each stopped process is a martingale, then pass to limits carefully.
  2. Domination / integrability: if you can show $|M_t|\le Z$ for an integrable $Z$, then $M$ becomes a uniformly integrable martingale, and many stopping arguments become safe.

You already saw a discrete-time version of this idea in gambler’s ruin: $S_{n\wedge\tau}$ is bounded by $\max(A,B)$, which is exactly the kind of domination that makes limit-passing legal.

This “UI is the hidden latch” theme will reappear constantly (Girsanov, stochastic exponentials, etc.).
